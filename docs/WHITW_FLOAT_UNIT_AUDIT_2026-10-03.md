# 荒芜拉普兰德浮游单元与 S3 狼头核对

## PRTS 资料

依据本地 PRTS 快照 `data/prts/snapshots/2026-09-12-prts/source/72848.json`：页面「荒芜拉普兰德」，revision 405723，修订时间 2026-06-23。该快照中的 S1、S2 与 S3 明确描述了两种机制：

| 技能 | PRTS 描述 | 机制归类 |
| --- | --- | --- |
| S1「慵怠者悲鸣」 | 被动使浮游单元 +1；开启后在全场随机锁定不移动的敌人。目标移动或倒下时重新索敌。备注要求目标一旦不再符合“不移动”条件便立刻取消锁定。 | 普通御械术师浮游单元；按自己的目标条件索敌。 |
| S2「逐猎狂飙」 | 浮游单元 +3、攻击范围扩大、攻击力提高；各自随机锁定敌人，单元攻击有 10% 几率令目标恐惧 1 秒。目标倒下后重新索敌，技能结束后返回干员身边。 | 普通御械术师浮游单元；攻击范围随技能扩大。 |
| S3「终幕·浩劫」 | 浮游单元 +2，且文案特别标出“特殊形态”。先向外散开 1.3 秒，再各自追逐较近的敌人；追上后恐惧并攻击，身边另有减速和每秒法术伤害。技能备注补充：抵达目标后，攻击行为与正常浮游单元相同。 | 特殊自由飞行狼头实体；独有的是实体移动和领域机制，抵达后的攻击行为沿用普通浮游单元语义。 |

御械术师分支特性还规定浮游单元造成法术伤害，并在连续攻击同一敌人时提高伤害，上限为干员攻击力的 110%。普通浮游单元与 S3 狼头不是同一个实体：S3 的散开、转向、追击、绕行和领域属于特殊形态；但它抵达目标后的攻击行为按 PRTS 备注与普通浮游单元相同。

## 代码核对与修正

原逻辑在所有写有“浮游单元”的技能上都设置 `whitwEyeCount`，而 `tickWhitwEyes` 只检查荒芜拉普兰德是否正在开技能。结果是 S1/S2 也会生成 S3 的自由飞行实体，并错误获得 S3 的散开追击、范围减速、周期法伤和必定恐惧。

现在按技能索引分流：

- S1/S2 使用普通御械术师浮游单元状态；每枚单元有独立目标与同目标伤害递增。S1 从全场选择当前没有实际位移的可选敌人；敌人每帧完成移动更新后才刷新浮游单元目标，因此速度属性为 0 但仍有位移、或速度大于 0 但本帧停留，都按实际位移判断。`staticRigid` 只代表物理刚性，不单独作为静止判定。S2 从扩大的技能攻击范围选择目标，并在命中时按黑板的 10% 概率施加恐惧。它们使用普通法术弹道，不进入 `battle.s.whitwEyes`。
- S3 才初始化 `whitwEyeCount` 并走自由飞行实体流程。S1/S2 不会再套用 S3 的领域伤害、减速或强制恐惧。
- 荒芜拉普兰德开 S1/S2 时不再把干员本体的普攻锁到某一个浮游单元目标。

普通浮游单元的攻击间隔取干员当时的攻击间隔；PRTS 快照没有提供 S1/S2 的独立飞行速度或飞行过程参数，因此没有套用 S3 的狼头飞行参数。

## 回归覆盖

`tests/native-flight-whitw.test.mjs` 保留 S3 散开、追击、领域、重索敌和返回用例，并新增：

- S1 在常态攻击范围外索敌静止敌人、排除本帧沿路径实际移动的敌人，且不生成自由飞行狼头。
- S2 的三枚普通浮游单元分别索敌，能造成法术伤害，恐惧按黑板概率结算，且不会触发 S3 的减速领域。
- S3 使用特殊狼头状态，不复用 S1/S2 的普通浮游单元状态。
