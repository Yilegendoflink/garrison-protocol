## 资料优先级与本期数据

1. `data/modes/alliance-lower/source.json`：`season.battleDataDict[modeId][round]` 的 `bossId → levelId`、`common.bossInfoDict` 的战斗 ID、`season.bossInfoDict` 的权重与最终生命。不要只凭 PRTS 通常图鉴的 `maxHp` 建最终血条。

## PRTS 行为拆解

### `boss_4` 昆图斯

[PRTS 敌人页](https://prts.wiki/w/盐风主教昆图斯)；[子代装置页](https://prts.wiki/w/子代)。本期正式单人关卡使用 0 级敌人资料与本期覆盖。

| 行为 | 本期参数与效果 | 实现归属 |
| --- | --- | --- |
| 本体与普攻 | 静态刚体、自缚、不可阻挡；PRTS 原表受击矩形长 4.95 × 宽 2.95、向上偏移 1。按用户指定，native 占位与实际受击区改为地图右上角 2 列 × 3 行，最终回合备战显示预览。优先选防御最高的 **2** 名我方单位，锁定后 **0.4 秒**造成攻击力 100% 物理伤害，附加攻击力 20% 神经损伤。 | native 受击区与部署预留共用 2×3 区域；按防御排序、延迟伤害走共用能力；选两人及神经损伤倍率从本体配置。静态刚体沿用 `native-shift` 语义，不能误设成完全失衡免疫。 |
| 阶段 | 受到伤害跨越每 33% 已损生命阈值，或开战后 75/200 秒，依次进入第二/第三形态；攻击力分别为基础值的 1.4/1.7 倍。进入新形态启用对应技能组，形态期 CD 独立初始化。 | 血线/时间触发和形态时钟可复用；阈值公式、技能组切换和攻击倍率为昆图斯专有。 |
| 大潮 | 第一/二/三形态 CD：45→40、15→35、1→3.5 秒；全场法术伤害 + 神经损伤。数值读各 `Tidewater*` 技能黑板（第三形态均为攻击力 20%）。 | 全场多目标伤害可复用；逐形态目标、伤害类型和损伤由专有处理器组合。 |
| 崩坍 | CD：37→40、4→40、13→40 秒；选防御最高的 2/4/8 人，**1 秒后**造成攻击力 140% 物理伤害。 | 共用防御排序、延迟伤害；目标数与技能时序为专有。 |
| 断裂生殖 | 原关卡技能组有 `SummonTentac*` 三形态 CD，按 `dslily_dstnta` 分支激活预置子代。 | **用户明确要求此召唤技能忽略**：三个 prefab 在 `ignoredSkillPrefabs` 中过滤，不触发子代，也不把原关卡预置点伪造到玩家所选地图。 |
| 子代 | 原关卡预置了四个 `trap_039_dstnta` 实例。 | 当前口径下不会生成，不属于本轮实现与素材验收范围；只有用户改变豁免时才继续接入子代实体、目标锁定和攻击。 |
| 物种爆发 | 单人第三形态 `Doom` 200→100 秒；同盟覆盖为 999→999 秒。 | 当前策略起始生命最高 45，最终战时限至多 145 秒且生命只会因漏怪下降；`Doom` 不可达并从逐名技能表过滤，不能把 200 秒初始 CD 错误提前到 100 秒。若以后调整计时上限，需重新核对。 |

注意：PRTS 页面同时列通常 1 级与 0 级，后者和本地正式单人档一致；页面的其它等级数值不能覆盖本期 `h07_04_s`。子代本身是可攻击装置，此处仅留作资料记录；当前最终战按用户要求忽略其召唤技能，不生成子代。

| 行为 | 本期参数与现状 | 实现归属 |
| --- | --- | --- |
| 普攻/天赋 | 本期黑板：无视 20% 防御；未阻挡时物理/法术闪避 20%；普攻附加攻击力 12% 神经损伤。PRTS 通常图鉴写 40%/40%/20%，此处**必须用本期覆盖**。 | 已在 `native-enemy-traits` 与伤害通路接入，现有定向测试覆盖。 |
| AOE | 初始/周期 CD **5/10 秒**，半径 2，攻击力 80% 物理伤害、20% 神经损伤，可命中迷彩；优先级高于闪现。 | 已在 `native-enemy-skills` 接入，目标/打断/CD 测试已有；最终关卡上仍要做真实战斗与视觉核验。 |
| 闪现/幻影 | 初始/周期 CD **10/15 秒**；受阻挡时沿下一检查点方向移动 1.5 格，成功后在起点生成本期 `enemy_2017_csphts` 幻影。幻影仍需本期 200 基础攻击与 20%/12% 本期参数。 | 已有路径、0.5 秒保护、幻影生成、存档恢复回归。正式最终战须用所选 Boss 关卡的路线，而非随机地图的普通敌人路线。 |
| 最终场地路线 | 原表 `h07_05_s` 的 Boss 路线索引 **4**，有 **19 个巡逻检查点**，最后不应按普通敌人进入蓝门而当作胜利/漏失。 | 最终阶段专属路径与结算规则；闪现继续调用现有路径逻辑。 |

| 行为 | 本期参数与效果 | 实现归属 |
| --- | --- | --- |

## 施工顺序与验证门槛

1. **共享最终阶段**：Boss 抽取、原关卡资料、最终血量、`100+HP` 时限、普通增援与胜负已接通；普通回合使用 `leftNormal/rightNormal`，最终回合使用抓取数据中的 `leftBoss/rightBoss` 拼接场地，Boss5 巡逻环按该场地运行，Boss4/7 固定占据右上角 2 列 × 3 行并在最终回合备战预览。切换 Boss 场地时单位回到整备区重新部署。定向测试覆盖地图裁切、权重、胜/败、读档、入口漏怪和站桩位置。
2. **逐名能力**：Boss5 的 AOE/闪现/幻影、Boss4 的高防双目标延迟普攻/三形态/大潮/崩坍、Boss7 的冰凌/自然涌动/半血伤害减免均已接入并有 `step()` 回归。昆图斯的 `SummonTentac*` 按用户要求忽略；Doom 不由当前逐名 handler 执行。
3. **剩余范围**：Boss1/2/3/6 与隐秘核心8/9/10仍未开放；7套本体 Spine 原始资产已收集，但战斗仍画头像。Spine 动画需先解决 Runtime 许可/分发方式，再进行动作、比例、朝向和攻击反馈验收。
4. **收口**：构建包、readiness、AGENTS 和本计划保持一致；不要将 `acceptedScopeComplete` 改为 true，也不要把上述三名描述成整套最终 Boss 范围已经完整。

### 已锁定的场地口径与剩余验收

- 最终阶段保留玩家开局抽中的阵地，不切换到 BOSS 专属地图；Boss5 用环线，Boss4/7 占据右上角 2 列 × 3 行。每张图均检查区域边界与中心落点。
- 击破本体当帧完成整场并结算，普通增援/幻影不延后胜利，也不能在胜利后继续伤人。
- 昆图斯子代属于被用户明确忽略的召唤技能范围，因此其 Spine 与攻击链路本轮不收集、不接入。

当前 `boss_4/5/7` 的功能性最终战和逐名机制测试已接入；昆图斯与萨米的意志占据地图右上角 2 列 × 3 行，备战阶段显示预览并保留该区域，卢西恩使用巡逻环。昆图斯召唤按用户明确口径忽略。Spine 播放仍待合规可分发的渲染方案，且 `boss_1/2/3/6`、隐秘核心不在此批开放范围。
