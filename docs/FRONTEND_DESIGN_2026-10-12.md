# 前端页面调整

设计依据：`frontend-design`。先提交自选系统与选择弹窗（`0610fc3`），再调整 native 页面表现。

## 设计方案与复核

这是围绕 11×7 战场、干员编制和逐回合作战的同人模拟器。大厅的核心内容是开局设置和真实阵地，而非数据规模宣传。用户明确要求保留原设计的绿色辉光、扫描线与终端风格。沿用六色：屏幕底色 `#081519`、面板 `#0d2023`、边界 `#2b5754`、正文 `#eafaf3`、操作绿 `#79dcb7`、提示黄 `#f0d18a`；危险／生命／阶级继续使用原有语义色。

字体使用本机 `Bahnschrift` 配合可用的思源黑体／`DengXian`／`Microsoft YaHei UI`。标题与正文共用字族，标题用中等字重，数据只用等宽数字，不以等宽字体和大写标签装饰全页。无远程字体、无新增运行依赖。

布局：大厅左侧放标题，右侧集中显示难度、阵地和开始操作；下面分别放更新摘要与资料入口。用户已要求移除大厅阵地预览卡片，地图缩略图只保留在开局简报。资料页、简报与配置页使用同一字号、表单和面板规则，战斗界面保留现有棋盘／档案／手牌的占位与层级。

```
卫戍协议 / 盟约下半                         版本与更新
标题与简介                                开局设置、操作按钮
更新摘要                                  战前准备与资料工具
```

复核：保留已有辉光、扫描线与终端背景，优化不以换配色或抹去游戏风格为目标。删除无业务含义的编号、重复英文眉题、虚假在线状态和装饰箭头。分区边界表示操作区域，不给每段文案加卡片，也不新增重复的入场动效。

用户追加要求更多参考原作。参考入口为 [明日方舟官方图文页](https://ak.hypergryph.com/special/ad-brand-2026/bi/index.html) 与 [官方游戏展示图](https://web.hycdn.cn/arknights/special/ad-brand-2026/bi/assets/feature_01.f24e8557.jpg)。保留本项目绿色终端锚点，采用切角面板、较窄的副标签、明确的主操作与头像框。官方图片入口已定位，但浏览器截图超时；本记录不将其记作原作逐画面视觉对照通过，不新增未经确认的“官方同款”素材。

## 验证边界

构建、真实 bundle DOM 宿主与相关页面回归确认入口和行为。浏览器工具先前拒绝本地 `file:` 页面，本轮不绕过该限制；因此不声称完成实际浏览器截图或手机视觉验收。

已实施：大厅的开局设置；准备页、简报、策略选择、自选弹窗、战绩、编制台和战斗控件的字号／间距；有用途的切角面板与头像框。`dist/native-shell.css` 作为最后一层样式加载，仅调整排版和局部面板，不覆盖原始终端背景、绿色辉光、扫描线、地图语义色和回合演出。移除大厅阵地预览后，同时删除其专属样式及无用数据读取，阵地选择仍由原有开局链路处理。

原前端调整构建通过，页面相关回归 **27/27** 通过；当时全量 **1488 项中通过 1455 项、失败 33 项**，失败均为此前已有问题，无新增失败。记录位于 `artifacts/frontend-design-build.log`、`artifacts/frontend-design-targeted.log` 与 `artifacts/frontend-design-full-test.log`；这些日志为本地验收产物。阵地预览移除后，相关用例改为确认大厅没有此卡片且阵地选择仍正确进入新局，另保留简报缩略图回归。原有结束横幅测试仅移除文案末尾箭头要求，保留结束后必有「回到大厅」的功能门禁。
