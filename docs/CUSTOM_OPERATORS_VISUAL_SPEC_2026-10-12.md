# 五名自选干员技能视觉效果规格

日期：2026-10-12。状态：十五个技能的信息表现需求已确定，程序化画布表现和资源 UI 已接入，见 [实装记录](CUSTOM_OPERATORS_IMPLEMENTATION_2026-10-12.md)。完整原作外观与真实浏览器逐技能视觉验收尚未完成。

本规格用于当前头像画布中的程序化表现，覆盖开技、攻击／命中、持续状态、附属对象、资源变化与结束清理。技能判定依据 [PRTS 数据与机制核对](CUSTOM_OPERATORS_PRTS_AUDIT_2026-10-12.md)，接入顺序依据 [自选系统实施方案](CUSTOM_OPERATORS_PLAN_2026-10-12.md)。本文的颜色、线形、装饰与短暂淡出时长是本项目设计建议，不是 PRTS 对原作美术的确认。

用户已进一步要求绘制接近原作的表现。下列暂定颜色与形状仅作为可读性占位；后续制作以已观察的原作模型及实战画面为依据，逐技能确认轮廓、色彩、方向、节奏与消散方式。只有机制说明、没有视觉参考的部分不能标为原作相似验收通过。

## 表现约束

1. 画面必须让玩家看出技能正在做什么、打向谁、影响哪里、还有多少资源。粒子和镜头装饰可以后补，实际目标、范围、对象和资源信息必须保留。
2. 渲染只读战斗状态。攻击、伤害、治疗、移动、投放、扣弹药与状态结束都由逻辑层决定；不能等动画播放完再伤害，也不能根据画出的线反推连线或索敌。
3. 瞬时命中反馈读真实结算事件；持续标记、对象、范围与弹药读仍有效的逻辑状态。`s.events` 会裁剪，不能用它维持永久残影、DOT 层数或棋子激活方向。
4. 技能 4／7 级和模组 1／3 级的范围、段数、对象数及资源数直接取本局档案与结算结果。同一份特效规格适配全部档位，禁止为了好看把初始一影画成两影。
5. 地面几何与单位头像位置分开：范围、连线、爆炸中心和弹道使用真实地图坐标；敌人重叠时头像标记随显示偏移，不能把伤害区域挪到偏移头像上。
6. 未核定的规则照真实模拟状态画。望 S3 的 `x-1`／`x-6` 差异、陈剑气转向和余震时序不能由美术选择代替规则核定。
7. 所有动效用 `battle.s.time`，暂停冻结、倍速同步、恢复存档可重建。减少动效保留信息，移除旋转、碎片、长拖尾和强闪光。
8. 当前显示是头像加程序化特效。达到本文验收不等于 Spine 或原作逐帧视觉验收完成。

| 干员 | 建议主色／辅色 | 主要图形语言 | 必须另用形状区分 |
| --- | --- | --- | --- |
| 维什戴尔 | 焦橙 `#FF8A4C`／灰白 `#E9DCD2` | 炮弹、冲击环、裂纹、火星 | 残影是焰状标，锁定是准星，影是独立实体 |

| 阿斯卡纶 | 冷紫 `#A78DDA`／灰蓝 `#A7B6C8` | 薄刃、刻痕、低透明场 | 层数三格、嘲讽指示、闪避折线和治疗十字 |
| 望 | 墨青 `#618E91`／米白 `#E7DCC6` | 棋子、细连线、方向线段 | 实心 token 与空心跟子；待激活与已激活方向 |
| 克莱门莎 | 海青 `#65C5C2`／深蓝 `#547EAA` | 舱体、运输轨迹、漩涡、炮击 | 放逐舱轮廓、侵蚀条、十字落区、轰炸中心锁 |

建议以 64px 宽地块为参考：细线约 1.5px、核心边缘 2px、重要图标 10 至 14px、对象轮廓约地块宽的 25% 至 40%，按实际画布缩放。范围填充透明度建议不超过 0.12；锁定与承载关系使用高对比细边，不用大片不透明罩色。头顶数字使用暗底、浅字，避开血条与元素条。

这些尺寸是表现比例，不影响碰撞箱、半径、格位占用或技能范围。

## 共用天赋与状态表现

这些效果跨三个技能存在，先建立一套公共呈现，再由技能补充。不能每个技能重复画一份。

| 对象／状态 | 最低必要表现 | 清理依据 |
| --- | --- | --- |
| 维什戴尔残影 | 目标头像旁焰状印记；单份标记，不虚构层数；引爆时发出区别于余震的碎裂反馈 | 对应来源状态实际消失、目标退出、主人退出 |
| 魂灵之影 | 独立小实体及血条、迷彩状态、技能命中；被选中时显示当前本体范围关系 | 实体真实存在与退出；技能结束本身不清影 |
| 陈天赋闪避 | 本体旁一枚“待闪避”状态徽记；消费时折线闪避反馈；治疗发生时十字反馈 | 一次性闪避真实取得／消费；特殊再部署后的实际状态 |
| 阿斯卡纶死亡拘审 | 敌人旁一至三格刻痕与层数；每拍真实 DOT 小闪；详情中可查看来源和余时 | 来源、层数和期限；主人退出立即清除 |
| 望棋子 | 固定格内实心棋子，未激活细灰边、激活清晰边；选中时显示有效方向与连线层数 | token 的实际位置、激活状态和生命周期 |
| 望跟子 | 空心棋子／半透明影子，与实心 token 一眼可辨；可参与连线 | 跟子实际存在；本格发生角色部署或来源退出 |
| 克莱门莎侵蚀 | 复用元素损伤条／环；爆发时短促侵蚀破裂标；减防不是持续火焰 | 真实元素累计、爆发与冷却状态 |
| 克莱门莎随机强化 | 仅在本次真实暴击判定成功时用较亮斩光和短增强标 | 实际强化伤害事件，不依据随机再掷一次 |

同一敌人有多个来源的 DOT／残影时，头像旁保留一个紧凑类别标，选中详情再列来源；不把显示合并写回战斗状态。维什戴尔的迷彩存在阻挡例外，现有 `drawConcealOverlay`／`drawStatuses` 的统一阻挡隐藏门禁需在正式实现时与真实状态口径对齐，不能出现逻辑仍迷彩、画面图标已经消失的矛盾。

## 维什戴尔

规则来源：[维什戴尔固定版本](https://prts.wiki/index.php?oldid=435184)、[魂灵之影固定版本](https://prts.wiki/index.php?oldid=386827)。配色属于项目建议。

| 编号与技能 | 启动与攻击 | 持续信息与附属对象 | 结束与低特效 |
| --- | --- | --- | --- |
| WIS-V1 定点清算 | 强化攻击待发时本体一枚炮击徽记；实际发射后较亮炮弹，命中形成 1.1 半径冲击环；每次真实余震分别重绘震荡；实际眩晕用现有控制图标 | 残影由天赋共享层画，不为强化攻击额外复制；模组改变余震段数，初始三次与装 X 模组后的推导四次分开验收 | 强化普攻实际消耗时撤待发徽记，已发余震继续按真实事件反馈；低特效保留炮弹、余震各拍与控制标，去火星和碎片 |
| WIS-V2 饱和复仇 | 开技本体细边发亮；前半程分别画向实际三个目标的炮击；过载后实际四发连射逐发画，允许同一目标重复命中 | 本体小标签区分普通阶段／过载；技能时间条在实际切换时变化，25 秒中点为 12.5 秒；随机目标只能来自真实射击事件 | 停止／到期清本体技能边与阶段标签；低特效保留阶段、四发数量和目标，不用快速全头像闪烁表现连射 |
| WIS-V3 爆裂黎明 | 按实际生成数量出现一／两影；主目标上准星；重型炮弹命中画 2.5 半径爆炸，实际残影引爆另画碎裂印记 | 本体显示六发弹药；弹药只随实际消耗变化；锁定依真实目标字段，影按实体画；锁定切换有明确转移反馈 | 技能结束清锁定／技能边，保留真实存活的影与残影；已发弹体是否继续显示遵守逻辑；低特效保留准星、影、弹药、爆炸边界 |

WIS-A：主攻击、余震、残影爆炸必须有三类形状或节奏区别。不能用一个大爆炸动画覆盖所有段数，让玩家误以为只命中一次。

WIS-B：只有真实引爆才出现残影爆炸，S3 的 100% 概率不代表开技即全场爆炸。影技能是小型法术命中加停顿，不画成另一发重炮，也不虚构普攻。

WIS-C：炮弹抛物线高度可用纯显示偏移，地面投影和落点仍跟随逻辑。影生成用局部淡入，不挡住合法格判断；没有合法位置时不得播放成功生成的实体。

## 赤刃明霄陈

| 编号与技能 | 启动与攻击 | 持续信息与附属对象 | 结束与低特效 |
| --- | --- | --- | --- |
| CHN-V1 赤霄·奔夜 | 开技本体朱红细边；每次真实攻击画两个清楚错开的短刀弧；目标获得沉默时挂既有沉默图标 | 本体保留技能状态，目标图标随本次沉默有效期；弱点伤害沿用真实结算类型提示，不为表现再算物理／法术结果 | 技能结束清本次技能边与已实际结束的沉默，不能清其它来源沉默；低特效保留二段刀弧、沉默标 |

| CHN-V3 赤霄·天喟 | 启动生成可转向剑气，表现为有箭头的窄剑气带；每次真实转向更新箭头；命中时局部刀弧；本体后续各目标的三段剑击逐段画 | 剑气的真实位置／方向始终可见；选中时显示剩余当前路径信息而不是假想全路线；本体范围取 `3-12`，不得画全场圆圈 | 本体技能与剑气各自按逻辑生命期退出；不能因头像技能边结束就提前删独立弹道；低特效保留剑气载体、箭头、转向和命中段 |

CHN-A：S2 的残像只表达瞬时斩击过程，不创建可被选中、占格或阻挡的假实体；本体当前位置与状态仍来自真实阶段。空中目标的斩光落在目标显示高度，移动终点则按实际地面格表示。

CHN-B：S2 的六秒倒计时从特殊再部署后开始，不能与十斩共用一个从开技开始递减的圈。没有合法目标格而返回原位仍需有真实再部署反馈。

CHN-C：S3 剑气命中范围取逻辑碰撞几何。剑气可对空，后续三目标攻击限地面；不能只画一条始终水平的装饰直线掩盖实际转向。

## 显示层与事件需求

| 显示类别 | 必要的只读逻辑信息 | 瞬时表现事件 |
| --- | --- | --- |

| 影／棋子／跟子 | 实体或效果 ID、ownerUid、真实位置、tokenType、占格类别、激活方向 | 生成、触发、消耗、退出 |
| 轰炸 | 目标格、真实 cells、下一伤害时间、剩余拍数、结束时间 | 发射、每拍命中、占用结束 |

显示层不能通过技能描述正则估算剩余段数，也不能读取 PRTS 新版本覆盖本局存档。显示时的纯插值只平滑已知逻辑位置，不更新对象坐标或决定下一个目标。

首次实现建议在独立纯绘制模块 `dist/native-custom-fx.js` 中组织五组表现，由 `native-fx.drawFx` 调用，并登记 `scripts/build-browser.mjs`。现有 `drawCombatFx`、`drawZones`、`drawDisplace`、`drawStatuses`、`drawElementRing` 和弹药／SP UI 复用；专属表现接管某个事件后避免通用炮击、范围波和命中闪光再叠一整套。

需要补的不是每技能一张贴图，而是可复用的形状与独立对象：残影／锁定、魂灵之影、斩击阶段／剑气、DOT 层格、棋子／跟子／连线、放逐舱／放逐标、漩涡、五格轰炸框。头像画布阶段可用程序化形状完成这些对象的可辨识表现，原作纹理和 Spine 留作后续资源层。

## 绘制顺序和低特效要求

建议绘制顺序为：地形 → 低透明范围与棋子连线 → 单位／棋子／影 → 剑气／舱体／弹道 → 瞬时命中 → 必需状态、血条、元素条与资源 → HUD。现有 `drawFx` 在单位之后、部分状态之前，接入时需拆分地面层和覆盖层，不能直接把大片区域盖到头像上。

大爆炸不遮 HUD、不盖住血条、不让屏幕整块闪白、不做镜头摇动。密集伤害可合并同格装饰粒子，但每个实际目标、标记和伤害计数继续正确；多来源实体和锁定不可为了性能合并成一个对象。

减少动效必须保留：所有实体轮廓、真实弹道位置、剑气方向、棋子连线与激活、各技能实际范围、锁定／放逐／DOT 状态、阶段切换、充能与弹药、每个真实伤害拍的简短反馈。可删除：火星、碎片、水花、雾、旋转、人物残像和重复的装饰环。

短命中淡出建议 0.12 至 0.24 秒，开技提示建议 0.3 至 0.45 秒；这是纯显示窗口，不改变 0.4 秒连斩、余震延迟、每秒 DOT 或任何结算间隔。同格高频命中用描边与局部亮点，避免高频大面积闪烁。玩家不能只靠颜色或声音识别阶段。

## 素材核查与原作表现边界

2026-10-12 通过 PRTS 资源元数据确认五名干员都有默认正面与背面模型入口，共十个视角。来源地址与 SHA-256 保存于 `data/prts/research/custom-operators-visual-2026-10-12/spine-metadata.json`。

后续浏览器复核已逐个打开五人模型，并检查上述代表动作；原始 metadata 与正面动画解析清单分别保留。完整动作至技能事件的对应关系，以及独立弹道、爆炸、剑气、棋子、舱体和轰炸素材仍未逐件确认。不能把角色模型可下载当作十五技能特效齐备，更不能把动作名 `Skill_03` 自动绑定为 S3 并标为已验收。

资源接入需逐项核定：本体动作、独立召唤物／装置、弹道、命中、地面持续效果；来源、适用朝向、缩放、脚底锚点、起止帧与循环方式各有记录。当前规格不依赖在线 PRTS 播放器，运行时仍离线加载构建后的资产。

## 接近原作的绘制依据

制作前给每个技能准备一条视觉参考记录，至少包含：默认服装／皮肤、来源链接、视频或动画片段、具体时间／帧号、对应阶段、颜色、主轮廓、行进方向、出现与消散方式，以及当前是否已经实际观看。动作、附属对象与目标特效分别记录，不由一个角色截图推导整个场景。

角色动作先用 PRTS 已有模型；独立粒子、弹道与区域优先用原作实战／官方演示逐帧观察。已找到 [陈的实战视频](https://www.bilibili.com/video/BV1DPF9zJESk/)与[克莱门莎的实战视频入口](https://www.bilibili.com/video/BV1r3ph61EFq/)，陈的视频页面可播放并列有技能解析章节，但本次尚未完成各技能时间点与画面的逐段核查。它们目前是待看片源，不能标为已确认特效外观。
