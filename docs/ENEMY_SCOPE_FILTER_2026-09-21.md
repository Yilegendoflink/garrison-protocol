# 敌人机制范围重筛（2026-09-21）

## 授权与判定

用户最新指示：“其中有很多机制都需要和特殊地块互动，这些地块在卫戍玩法中不存在，可以不实现相关效果。进行重新筛选”。据此不再为全敌人补齐引入缺席场地、场景装置或其派生NPC链。旧记录“仅搭桥豁免”“无预置也必须继续补生产者”被本次口径覆盖。

判定单位是**效果**，不是整名敌人。没有触发场地，只免除那个场景分支；保留无环境默认态、自身SP/CD、形态、攻击、召唤和原生地形交互。已有干员/敌人能实际生成的对象也不能仅因地图未预置而排除。

## 结果与后续

39个旧跟踪组中，10组按范围豁免移出，1组只剩表现尾项单列，28组行为/验证继续保留（R3/M11/领袖14）。这不是新完成了11组机制，也不改历史测试结论。

本轮不删除已完成通用模块，不部署新装置，不自动解除随机池限制。今后开发与验收以 [剩余清单](ENEMY_BEHAVIOR_REMAINING.md) 的保留范围为准，历史逐批记录仅用于追溯。
