# 编制台活动分组

2026-09-21：本期 215 条敌人档案使用 PRTS 的「登场活动」属性分组，来源快照为 `data/prts/enemy-activities.json`，逐条保留页面链接。同名干员使用「(敌方)」页面；上下位和同名不同 ID 的敌人仍各自保留记录。活动是登场归属，不代表只会在该活动出现。

- 默认配置按原模板的活动拆分，同档同活动合并去重，并剔除未准入敌人；原有敌人成本、预算、数量范围和早期成本上限保留。允许单敌人模板，不通过混入别的活动凑种类。
- 旧存档/导入表保留预算、费用与数量配置，载入时拆分混合模板。随机抽取也再次按活动拆分并过滤未准入敌人；有非空池时不抽取空池，全部为空才沿用占位敌人。实战按整档随机选模板。

更新资料：`node scripts/sync-enemy-activities.mjs`；随后 `npm run build`。构建会校验每条活动归属、默认模板同活动与逻辑资格；新敌人或活动变化须逐条复核默认 JSON，不能靠分类放开机制资格。


验证：`node --test tests/native-wave-*.test.mjs`。
