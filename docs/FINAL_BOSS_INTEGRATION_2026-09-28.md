# 最终 Boss 战接入计划（2026-09-28）

状态：**boss_4/5/7 已接入最终战主流程并进入抽取池。** 三者共享本期血量、`100 秒 + 开战剩余生命` 倒计时、30 名增援、漏门扣时、本体击破即胜和逐角色 DPS 曲线。最终回合使用关卡抓取数据中的 `leftBoss/rightBoss` 地图裁切拼接出的 21×7 场地；进入该阶段时单位回到整备区，在 Boss 场地重新部署。卢西恩沿 Boss 场地地面环线巡逻；昆图斯与萨米的意志自缚站桩，固定占据场地右上角 2 列 × 3 行，最终回合备战时预览该区域并禁止干员和召唤物进入。昆图斯「断裂生殖」及三形态 `SummonTentac*` 召唤技能按用户明确口径忽略，不生成子代。战斗画布仍用放大的 PRTS 头像，Spine 动画未接入；其它常规 Boss、隐秘核心与最终视觉验收仍待完成。

首批 `boss_4/5/7` 的 PRTS 行为、现有实现与通用/专有能力拆分见 [专项施工单](FINAL_BOSS_4_5_7_PLAN_2026-09-28.md)。

## 目标规则

- 最终回合开战时锁定剩余目标生命 `hpAtStart`，时限为 **`100 + hpAtStart` 秒**。生命值是这次战斗的时间奖励，不在战斗中每变化 1 点就重算倒计时。计时使用战斗模拟时间，暂停不流逝、倍速按模拟秒流逝。
- Boss 有可击败的实际生命；在时限内击败本回合指定的 Boss 即获胜。到时仍存活、战斗中目标生命归零或被迫结束均不得判胜。随行召唤物是否影响清场与通关，由逐名规则登记；不能只用通用「敌人列表清空」判断 Boss 胜利。
- 结算沿用作战报告的总伤害、DPS、角色明细，并新增**可点击的逐角色全程 DPS 曲线**。胜利、超时、失败都能打开报告；图上时间范围统一为本阶段开始至实际结束。
- 路径型 Boss 在战场内巡游，不以进入蓝门作为正常退场条件；固定型 Boss 使用自己的占地、受击与绘制范围。两种形态都用同一个 Boss 身份和胜负结算接口，不能让位置表现改变伤害归属。
- 本轮是**真实 Spine（用户原文 spire）素材**。模型用于战斗绘制与动作；逻辑命中区域、施法时刻仍以战斗数据和逐名核定为准，不能从骨骼像素外形推算。

## 权威资料与差异

1. 本期实际 Boss 名单、权重、独立/同盟/隐秘核心档与血量以仓库 `data/modes/alliance-lower/source.json` 的 `common.bossInfoDict`、`season.bossInfoDict` 为数据源。前者给战斗敌人 ID，后者给权重、血量和 `isHidingBoss`。PRTS [下半期盟约记录·领袖](https://prts.wiki/w/卫戍协议：盟约_下半/PRTS盟约记录#领袖)用于交叉核对本期改值；敌人单页的普通关卡数值不能直接覆盖本期。最终 Boss 原表血量按四人联机配置，native 模拟默认取原值的 75%（×0.75），在「协议自定义 → 敌人波次」可调整；对局开始时固定倍率并随存档保存。
2. `source.json` 的 `turnInfoDataDict[*].bossTurnHpReduceTime` 历史字段仍是 **150**；native 最终 Boss 战明确覆盖为用户指定的 `100 + hpAtStart`，UI、测试和 readiness 不得再把 150 当最终战时限。当前 30/25 HP 示例局因此为 130/125 秒。
3. PRTS 敌人页给出攻击、技能 CD、SP、阶段与召唤物说明；本期修正优先看上述盟约记录和本地关卡覆盖。PRTS 自己提示敌人页为通常数据；每个 Boss 上线前需把原表 `enemyDbRefs`、本期黑板、Wiki 技能表逐项对照。
4. 原项目对「缺席特殊地块/装置」的豁免仍适用于 Boss 独特机制筛选，详见 `docs/ENEMY_SCOPE_FILTER_2026-09-21.md`。Boss 自身召唤的武器、弹体和敌人不能仅因地图未预置而豁免；昆图斯的 `SummonTentac*` 是用户明确指定忽略的逐名例外。

### 逐名实施卡模板

每做一个 Boss，先在本页或独立子页补全：本期 `bossId/enemyId`、难度血量与本地关卡覆盖；移动/固定与逻辑受击区；普通攻击每一种；CD 技能的初始/周期 CD；SP 技能的初始/上限/回复/消耗；施法优先级和动作时刻；生命阈值、召唤、无敌/护盾、死亡结算；子实体及所需 Spine/弹体/音效；与本期地图及豁免范围的交叉；原表字段与 PRTS 页面锚点；至少一条真实 `step()` 用例、一次浏览器视觉核验和存档恢复用例。未核定的数值写「待核」，不填猜测值。

4. **隐秘核心**：另做 `boss_8…10` 的附加能力、血量、子实体和模型核验；触发条件/回合逻辑另行确认，不能由普通 Boss 通关顺手假定。
