# 自选干员实装记录

日期：2026-10-12。分支：`codex/custom-operators`。首批五人可运行实现已接入 native 客户端；本记录区分代码接入、自动回归与原作对照验收。未发布到 `main`，未修改全局可玩对等／验收完成标记。

## 使用方式

大厅 → 战前准备 → 自选干员：最多两个位置，各自选择五阶或六阶，可留空。同一干员不能占两个位置。选择立即本地保存，创建战前简报时复制到本局，后续大厅修改不影响已创建的对局；存档恢复使用存档中的配置。

所选干员进入对应阶级的商店及适用获取池，不在开局赠送。五阶库存 16、六阶库存 8，仍走原有价格、三合一精锐、出售库存账本、禁用盟约和整备区容量规则。技能在战前准备的干员页配置，也可沿用局内同名技能切换；切换自选名单保留有效技能默认值。

自选位置现以卡片显示，点击「选择干员／更换干员」打开独立弹窗。弹窗支持八职业筛选，按名称、别名或盟约搜索，两种条件同时生效；另一位置已选的干员标明占用并禁止重复选入。卡片可展开所属盟约的效果和初始／精锐技能说明，点击 S1／S2／S3 即保存默认技能；主页面同步显示。移除位置保留技能默认设置。搜索更新只替换结果区，保留输入焦点；弹窗有键盘焦点约束，可用 Esc、关闭按钮或遮罩退出，退出后焦点返回原位置按钮。

维什戴尔、阿斯卡纶为协防干员；陈、望为炎；克莱门莎为阿戈尔。初始和精锐均无自带卫戍特质，保留职业、天赋、技能、模组及外部装备／盟约／策略效果。

初始状态均精二 1 级、技能 4 级、无模组；精锐均精二 60 级、技能 7 级。前四人固定 X 模组，五阶精锐 1 级、六阶精锐 3 级；克莱门莎没有虚构模组。配置页展示两态裸档案生命／攻击／防御。
